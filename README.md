# Flashcard Quiz App

## About the Project

The Flashcard Quiz App is a simple and interactive learning application that helps users practise questions and answers using flashcards.

## Features

* Display flashcards with questions and answers.
* Show the answer when requested.
* Navigate to the next and previous flashcards.
* Add, edit, and delete flashcards.
* Simple and user-friendly interface.

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
